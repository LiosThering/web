# 9998 · HTML 即时预览器

把 HTML 代码粘进去，就**当代码一样执行并实时渲染**；刷新网页即清空，不做任何缓存。配上「演示模式」可全屏展示，适合作为轻量 PPT / 原型演示替代。

## 功能
- **实时渲染**：左侧粘贴 HTML，右侧 iframe 实时执行（支持 `<style>`、`<script>`，与原生网页一致）。
- **不缓存**：完全不使用 `localStorage` / `sessionStorage`。刷新网页后你粘贴的内容全部消失，回到默认的示例。
- **演示模式**：隐藏编辑区与工具条，仅留全屏预览，配合全屏按钮可作 PPT 展示。
- **按钮**：
  - `▶ 运行`：立即重新渲染（也支持输入时自动防抖渲染）。
  - `⛶ 演示模式`：切换全屏演示。
  - `载入示例`：填入一份两页的 PPT 式示例。
  - `清空`：清空编辑区。
- **手机适配**：窄屏自动改为上下布局。

## 使用
直接用浏览器打开 `index.html` 即可。要分享给别人，随仓库一起部署到 GitHub Pages 后访问 `/9999` 的上一级目录 `9998/`。

## 说明
- 渲染用 `iframe` + `sandbox="allow-scripts allow-modals"`，脚本可运行，但与原页面隔离，安全且忠实。
- 若粘贴的是完整 `<!DOCTYPE html>` / `<html>` 文档，则原样执行；否则自动包裹成基础文档再渲染。
- 想「刷新即清空」是刻意设计：不持久化任何内容，避免泄露草稿。
