# 我的简便网页收集

把平时好用的小网页按编号放在不同文件夹里，从 `9999` 往下一直到 `0`，慢慢积累。

每个文件夹里都有一个 `index.html`，可直接用浏览器打开，也能通过 GitHub Pages 访问（例如 `https://<用户名>.github.io/<仓库名>/9999/`）。

- 根目录 `index.html`：这些网页的**导航首页**（部署后访问仓库根 `https://<用户名>.github.io/<仓库名>/` 即可看到卡片入口）。
- 本文件 `README.md`：记录每个编号文件夹的 `index` 分别是做什么的（仓库文档）。

## 目录

| 文件夹     | 网页     | 说明                                                 |
| ------- | ------ | -------------------------------------------------- |
| `9999/` | 内容块生成器 | 像搭积木一样生成「固定 / 可变」内容块，一键复制到剪贴板；左下橙黄刷新、右下浅绿复制，手机自适应。 |

> 之后每加一个网页：新建下一个编号的文件夹（如 `9998`），放入 `index.html`，并在上表补一行说明，同时到根目录 `index.html` 的 `SITES` 数组里加一行，然后提交推送即可。

## 怎么部署（谁都能用）

1. 确保仓库是**公开（Public）**的（GitHub Pages 免费版只支持公开仓库）。私有仓库会一直 404。
2. 仓库 → **Settings → Pages** → Build and deployment → Source 选 **Deploy from a branch** → Branch 选 **main** → Folder 选 **/ (root)** → Save。
3. 去仓库 **Actions** 标签，等 `pages-build-deployment` 工作流变绿（约 1–3 分钟）。
4. 访问 `https://<用户名>.github.io/<仓库名>/` 看到导航首页；点进去 `9999/` 即用。手机同样可访问。

## 怎么加新网页

1. 新建文件夹，名字用下一个编号（如 `9998`）。
2. 在里面放 `index.html`。
3. 在上方「目录」表格里加一行说明。
4. 在根目录 `index.html` 的 `SITES` 数组里加一行（id / name / desc）。
5. 提交并推送到 GitHub，Pages 会自动更新。
