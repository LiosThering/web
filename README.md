# 我的简便网页收集

把平时好用的小网页按编号放在不同文件夹里，从 `9999` 往下一直到 `0`，慢慢积累。

每个文件夹里都有一个 `index.html`，可直接用浏览器打开，也能通过 GitHub Pages 访问（例如 `https://<用户名>.github.io/<仓库名>/9999/`）。外层这个 `README.md` 负责记录每个文件夹里的 `index` 分别是做什么的。

## 目录

| 文件夹 | 网页 | 说明 |
| --- | --- | --- |
| `9999/` | 内容块生成器 | 像搭积木一样生成「固定 / 可变」内容块，一键复制到剪贴板；左下橙黄刷新、右下浅绿复制，手机自适应。 |

> 之后每加一个网页：新建下一个编号的文件夹（如 `9998`），放入 `index.html`，并在上表补一行说明，然后提交推送即可。

## 怎么部署（谁都能用）
1. 在 GitHub 新建仓库，把整个文件夹结构（`9999/`、`README.md` 等）推送上去。
2. 仓库 → **Settings → Pages** → Source 选 **main** 分支、**/ (root)**，保存。
3. 约 1 分钟后，访问 `https://<用户名>.github.io/<仓库名>/9999/` 就能用；手机同样可访问。

## 怎么加新网页
1. 新建文件夹，名字用下一个编号（如 `9998`）。
2. 在里面放 `index.html`。
3. 在上方「目录」表格里加一行说明。
4. 提交并推送到 GitHub，Pages 会自动更新。
