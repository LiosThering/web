# 9999 · 内容块生成器

一个纯静态、免后端、手机自适应的单页工具：像搭积木一样生成「固定 / 可变」内容块，一键复制全部内容。

## 功能
- **固定块**：写什么就是什么，刷新不变。
- **可变块**：填入多行候选，点刷新按钮随机抽一行显示。
- 左下角**橙黄色刷新按钮**：刷新所有可变块一次后自动隐藏（防止误改结果；刷新网页可再用）。
- 右下角**浅绿色复制按钮**：把当前所有块内容拼好复制到剪贴板。
- 内容自动存浏览器本地（localStorage），关掉再打开还在。
- 响应式布局，手机端可用。

## 本地预览
直接用浏览器打开本文件夹的 `index.html`；或在仓库根目录起一个静态服务后访问 `/9999/`：
```
python -m http.server 8000
# 浏览器访问 http://localhost:8000/9999/
```

## 部署（GitHub Pages）
本文件夹位于仓库根下的 `9999/`，开启仓库 Pages（main 分支 / root）后，访问：
`https://<你的用户名>.github.io/<仓库名>/9999/`

手机访问同一网址即可，布局自动适配。

## 自定义
- 改颜色：编辑 `index.html` 里 `<style>` 的 `--refresh`（刷新按钮橙黄）、`--copy`（复制按钮浅绿）。
- 改默认块：编辑脚本里的 `defaultBlocks()`。
- 刷新按钮想「每次都刷新、不隐藏」：把 `refreshAll()` 里 `btn.classList.add('hide')` 那行删掉。
